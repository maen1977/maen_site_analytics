تثبيت فعلي للهيدر في نسخة الكمبيوتر فقط، بدون تكبير.

الملف المعدل:
- public/index.html

ماذا يفعل:
- يجعل الهيدر الحالي ثابتاً أعلى الشاشة أثناء النزول.
- لا يغير حجم الهيدر أو الخطوط أو التبويبات.
- يضيف مسافة تلقائية محسوبة حسب ارتفاع الهيدر حتى لا يغطي المحتوى.
- لا يغير دوال التبويبات أو showPage أو onclick.
- لا يلمس كأس العالم أو ملفات التحديث.
