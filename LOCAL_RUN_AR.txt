طريقة تشغيل الموقع محلياً
=========================

سبب المشكلة السابقة:
ملف الموقع الرئيسي موجود داخل public/index.html، ولم يكن هناك index.html في جذر المشروع.
لذلك عند فتح المجلد كامل أو تشغيل Live Server من الجذر قد لا يظهر الموقع.

الطرق الصحيحة الآن:

1) أسهل طريقة:
افتح ملف index.html الموجود في جذر المشروع.
سيحوّلك تلقائياً إلى public/index.html.

2) تشغيل محلي أفضل على ويندوز:
اضغط مرتين على ملف:
تشغيل-محلي.bat
ثم افتح:
http://localhost:8080

3) تشغيل محلي على Mac:
افتح ملف:
تشغيل-محلي.command
ثم افتح:
http://localhost:8080

4) تشغيل Netlify Functions محلياً:
من داخل مجلد المشروع شغّل:
npm install
npx netlify dev

ملاحظة:
فتح الموقع محلياً يعرض قاعدة الترددات المخزنة داخل الموقع.
التحديث الأسبوعي وملفات التقارير تعمل بالكامل عند النشر على Netlify أو عند تشغيل netlify dev.
