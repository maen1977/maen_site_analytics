# إزالة معلومات القنوات الناقلة من قسم كأس العالم

هذا التعديل يزيل ظهور معلومات القنوات الناقلة من كل كروت مباريات كأس العالم داخل الموقع.

## ماذا يغير؟

- يخفي قسم: القنوات الناقلة.
- يخفي أسماء القنوات مثل beIN SPORTS وغيرها داخل مباريات كأس العالم.
- يعمل على نسخة الحاسوب ونسخة الموبايل.

## ماذا لا يلمس؟

- لا يلمس التحديث كل 15 دقيقة.
- لا يلمس GitHub Actions.
- لا يلمس ملفات JSON.
- لا يغير ترتيب الأدوار أو ميزة أنت هنا.
- لا يغير باقي أقسام الموقع.

## طريقة التركيب

1. فك الضغط.
2. انسخ محتويات هذا المجلد إلى جذر مشروع GitHub.
3. شغل الملف:

```bat
APPLY_REMOVE_WORLDCUP_BROADCASTS.bat
```

4. اعمل Commit بالرسالة الموجودة في `COMMIT_MESSAGE.txt`.

## رسالة Commit

```text
Remove World Cup broadcast channel info from match cards
```
