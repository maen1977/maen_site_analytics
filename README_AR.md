# إصلاح بطاقة المباراة القادمة داخل قسم كأس العالم 2026

هذا التعديل يبدّل بطاقة **المباراة القادمة للأردن** داخل قسم كأس العالم إلى بطاقة عامة باسم:

**المباراة القادمة**

وتعرض داخل نفس المربع الحالي:
- علم المنتخب الأول واسم المنتخب.
- علم المنتخب الثاني واسم المنتخب.
- وقت المباراة بتوقيت الأردن.
- الملعب إذا كان موجودًا في البيانات.

## مهم

هذا التعديل لا يلمس:
- GitHub Actions.
- التحديث التلقائي كل 15 دقيقة.
- ملفات JSON.
- باقي أقسام الموقع.

التعديل فقط على:
- `public/index.html`
- `public/index_phone.html`

ومرفق معه ملف `worldcup-current-focus.js` كما هو حتى لا ينكسر وسم **أنت هنا** إذا كان موجودًا عندك.

## طريقة التركيب

1. فك الضغط.
2. ارفع مجلد `public` إلى جذر مشروع GitHub.
3. وافق على استبدال الملفات المطلوبة.
4. اعمل Commit.
5. افتح الموقع بكسر الكاش:

`https://maensat.pages.dev/?v=next-match-card`
