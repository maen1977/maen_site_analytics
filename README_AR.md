# تعديل تقسيم أدوار كأس العالم 2026

هذا التعديل مخصص لمستودع:

`maen1977/maen_site_analytics`

## ماذا يفعل؟

- يقسم تبويب **الأدوار** إلى:
  - دور الـ32
  - دور الـ16
  - ربع النهائي
  - نصف النهائي
  - المركز الثالث
  - النهائي
- يفتح **نصف النهائي** افتراضيًا في الوضع الحالي.
- يعرض مواعيد المباريات بتوقيت الأردن.
- يحدث مباراتي نصف النهائي:
  - فرنسا × إسبانيا — الثلاثاء 14 يوليو 2026، الساعة 10:00 مساءً.
  - إنجلترا × الأرجنتين — الأربعاء 15 يوليو 2026، الساعة 10:00 مساءً.
- يحدث الخانات المطابقة للمباراتين 101 و102 في ملفات JSON الموجودة داخل `public/worldcup-2026`.
- ينشئ نسخة احتياطية من أي ملف يعدله بلاحقة `.bak-20260712`.
- يمكن تشغيله أكثر من مرة من دون تكرار كود الواجهة.

## التطبيق من جهازك

1. فك ضغط الملف داخل جذر مستودع `maen_site_analytics`.
2. افتح Terminal أو PowerShell داخل مجلد المستودع.
3. نفّذ:

```bash
node apply-worldcup-semifinal-fix.mjs
```

4. راجع الموقع محليًا بالطريقة المعتادة عندك، ثم ارفع التعديل:

```bash
git add public/worldcup-knockout-cards-ui.js public/worldcup-2026
git commit -m "Split World Cup knockout rounds and update semifinals"
git push
```

## التطبيق عبر GitHub Codespaces

- افتح المستودع.

- ارفع الملفات الثلاثة إلى جذر المستودع.
