# إزالة كرت كأس العالم من الرئيسية فقط

يا صديقي، هذا التصحيح مبني على ملف `public.zip` الذي رفعته أنت.

ما الذي يعمل؟
- يزيل كرت/زر **كأس العالم 2026** من كروت قسم **الرئيسية** فقط.
- لا يزيل زر كأس العالم من القائمة الجانبية.
- لا يزيل قسم كأس العالم نفسه.
- لا يلمس تبويب الأدوار أو المجموعات داخل قسم كأس العالم.
- لا يلمس التحديث كل ربع ساعة ولا ملفات GitHub Actions.

الملفات المعدلة فقط:
- `public/index.html`
- `public/index_phone.html`

طريقة التركيب:
1. فك الضغط.
2. ارفع مجلد `public` فوق الموجود في GitHub، ووافق على استبدال `index.html` و `index_phone.html` فقط.
3. اعمل Commit.
