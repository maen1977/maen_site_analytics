# إصلاح أنت هنا وترتيب بطاقة المباراة القادمة

هذا الإصلاح يعمل فقط داخل قسم كأس العالم 2026.

## ماذا يغيّر؟

1. يجعل مؤشر **أنت هنا** يختار أول مباراة إقصائية غير منتهية حسب رقم المباراة داخل الأدوار، حتى ينتقل من مباراة 73 إلى مباراة 74 ثم 75 وهكذا، بدل أن يقفز حسب وقت المباراة فقط.
2. يحافظ على اختيار المباراة المباشرة إذا كانت هناك مباراة شغالة فعلياً.
3. يحسّن مربع **المباراة القادمة** في الأعلى حتى تظهر أسماء المنتخبات كاملة وغير مقصوصة، حتى لو ظهرت فوق بعض.
4. يعمل على نسخة الحاسوب والموبايل.

## لا يلمس

- التحديث التلقائي كل 15 دقيقة.
- GitHub Actions.
- ملفات JSON.
- باقي أقسام الموقع.
