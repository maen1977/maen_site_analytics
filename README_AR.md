# إصلاح بطاقة المباراة القادمة لتتبع "أنت هنا"

هذا الإصلاح يعمل داخل قسم كأس العالم فقط.

## ماذا يفعل؟

1. يجعل مربع **المباراة القادمة** في أعلى قسم كأس العالم يختار نفس المباراة التي عليها علامة **أنت هنا**.
2. يعني بعد انتهاء مباراة 73، سيظهر في المربع مباراة 74 مثل **ألمانيا × البوسنة والهرسك** بدل القفز إلى مباراة أخرى حسب الوقت.
3. يكبّر خط أسماء المنتخبات داخل نفس المربع، ويجعل الأسماء فوق بعض حتى لا تنقص أو تظهر مقصوصة.
4. يعمل على نسخة الحاسوب ونسخة الموبايل.

## ماذا لا يغير؟

- لا يلمس تحديث كأس العالم كل 15 دقيقة.
- لا يلمس GitHub Actions.
- لا يلمس ملفات JSON.
- لا يلمس باقي أقسام الموقع.

## الملفات المعدلة

- `public/index.html`
- `public/index_phone.html`
- `public/assets/worldcup-current-focus.js` موجود كما هو ضمن الحزمة للمحافظة على نفس منطق "أنت هنا".
