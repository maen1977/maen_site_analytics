# ترتيب مباريات دور الـ32 حسب التاريخ والوقت

هذا التصحيح يغيّر طريقة عرض **دور الـ32 فقط** داخل تبويب **الأدوار** في قسم كأس العالم، بحيث تكون المباريات مرتبة حسب التاريخ والوقت بدل ترتيب رقم المباراة.

## ماذا يغيّر؟

يعدل الملفين:

- `public/index.html`
- `public/index_phone.html`

ويجعل دور الـ32 يعرض المباريات حسب `kickoff_jordan` أو `kickoff_utc` أو `date`.

## ماذا لا يغيّر؟

لا يلمس:

- التحديث كل 15 دقيقة
- GitHub Actions
- ملفات JSON
- ميزة "أنت هنا"
- مربع المباراة القادمة
- باقي أقسام الموقع

## طريقة التركيب

1. فك الضغط.
2. انسخ محتويات المجلد إلى جذر مشروع GitHub.
3. شغّل الملف:

```bat
APPLY_R32_SORT_BY_TIME.bat
```

4. اعمل Commit بهذه الرسالة:

```text
Sort World Cup Round of 32 matches by date and time
```

5. افتح الموقع بكسر الكاش:

```text
https://maensat.pages.dev/?v=r32-sort-time
```

## ملاحظة

باقي الأدوار مثل دور الـ16 وربع النهائي تبقى مرتبة برقم المباراة، لأن ترتيبها الشبكي يعتمد على المسار وليس الوقت فقط.
