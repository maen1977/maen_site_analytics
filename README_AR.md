# إصلاح عرض الأدوار داخل قسم كأس العالم 2026 فقط

هذا الملف يعدل `public/index.html` و `public/index_phone.html` فقط.

ماذا يفعل؟
- يجعل تبويب **الأدوار** يعرض المباريات كـ **كروت مباريات** بنفس شكل عرض مباريات كأس العالم في الموقع.
- يظهر اسم الدور، رقم المباراة، المنتخبات، النتيجة/الحالة، الوقت بتوقيت الأردن، الملعب، والقنوات إن وجدت.
- يحذف تحميل السكربت القديم `worldcup-knockout-cards-ui.js` من الصفحتين حتى لا يغطي على العرض الأصلي.

ماذا لا يفعل؟
- لا يلمس GitHub Actions.
- لا يغير التحديث كل ربع ساعة.
- لا يغير ملفات JSON.
- لا يغير تصميم باقي الموقع.

طريقة التركيب:
1. فك الضغط.
2. ارفع مجلد `public` الموجود هنا فوق مجلد `public` في مشروعك، ووافق على استبدال:
   - `public/index.html`
   - `public/index_phone.html`
3. اعمل Commit.
4. لا تشغل أي Action جديد. اترك التحديث الأصلي يعمل كل ربع ساعة.
