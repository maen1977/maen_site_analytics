# إصلاح حرية التنقل بين تبويبات كأس العالم

هذا التعديل يحل مشكلة رجوع قسم كأس العالم تلقائياً إلى تبويب **الأدوار** بعد الضغط على تبويب آخر مثل اليوم أو المجموعات.

## ماذا يفعل؟

- يبقي فتح **الأدوار** افتراضياً عند دخول قسم كأس العالم.
- بعد أن يضغط المستخدم على أي تبويب آخر، يبقى على اختياره ولا يرجعه الموقع للأدوار.
- ميزة **أنت هنا** تبقى شغالة داخل تبويب الأدوار.
- إذا خرج المستخدم من قسم كأس العالم ورجع إليه من جديد، يفتح الأدوار مرة أخرى بشكل طبيعي.

## ماذا لا يلمس؟

- لا يلمس التحديث كل ربع ساعة.
- لا يلمس GitHub Actions.
- لا يلمس ملفات JSON.
- لا يلمس التصميم العام أو باقي الموقع.
