# إصلاح عرض نتيجة المباريات التي لم تبدأ

هذا التعديل يغيّر منطق عرض النتيجة داخل قسم كأس العالم فقط.

## ماذا يصلح؟

- المباراة المنتهية أو المباشرة تبقى نتيجتها ظاهرة مثل: `1 - 0` أو `0 - 0`.
- المباراة التي لم تبدأ بعد تظهر بشرطة: `—` بدل `0 - 0`.
- هذا ينطبق على الأدوار، اليوم، الأردن، كل المباريات، ونسخة الحاسوب والموبايل.

## الملفات المعدلة

- `public/index.html`
- `public/index_phone.html`

## لا يلمس

- التحديث كل 15 دقيقة
- GitHub Actions
- ملفات JSON
- باقي أقسام الموقع
- ميزة "أنت هنا"
