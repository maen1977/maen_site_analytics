تعديل زر كتالوج الأجهزة واتساب - نسخة V2

سبب أن النسخة السابقة لم تظهر:
كان التعديل على index_phone.html فقط، بينما الموقع قد يفتح index.html على الموبايل أو حسب طريقة النشر.
هذه النسخة تعدل الملفين معًا:

public/index.html
public/index_phone.html

ما تمت إضافته:
- زر في قسم أجهزة الرسيفرات يظهر على الشاشات الصغيرة فقط.
- الزر يقرأ الأجهزة والأسعار والصور من نفس كروت الموقع.
- يحاول إنشاء صورة كتالوج واحدة ومشاركتها عبر واتساب.
- إذا لم يدعم الهاتف مشاركة الصورة، يفتح واتساب برسالة نصية فيها الأسماء والأسعار وروابط الصور.

طريقة الرفع:
1. فك الضغط.
2. انسخ مجلد public فوق public الموجود في مشروع GitHub Desktop.
3. وافق على الاستبدال.
4. تأكد أن GitHub Desktop يعرض تغييرين:
   public/index.html
   public/index_phone.html
5. اكتب رسالة commit:
   Add mobile devices WhatsApp catalog button V2
6. Commit ثم Push.

مهم:
بعد النشر افتح الموقع من موبايل أو اضغط Ctrl+F5. الزر مخفي على الكمبيوتر لأنه مطلوب للموبايل فقط.
