طريقة الرفع:
1. فك الضغط.
2. انسخ مجلد public فوق مجلد public الموجود في مشروع GitHub.
3. وافق على الاستبدال/الدمج.
4. من GitHub Desktop اعمل Commit ثم Push.

https://maensat.pages.dev/robots.txt
https://maensat.pages.dev/sitemap.xml

ثم ادخل Google Search Console > Sitemaps
واكتب:
sitemap.xml
