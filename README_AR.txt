تعديل زر كتالوج الأجهزة للموبايل فقط

الملف المعدّل:
public/index_phone.html

ماذا يفعل التعديل؟
- أضاف زر داخل قسم أجهزة الرسيفرات في نسخة الموبايل فقط.
- الزر اسمه: إرسال كتالوج الأجهزة واتساب.
- عند الضغط عليه يحاول تجهيز صورة كتالوج واحدة تحتوي كل الأجهزة والأسعار الموجودة حاليًا في الصفحة.
- إذا الهاتف يدعم مشاركة الملفات، تظهر نافذة المشاركة وتختار واتساب ثم الزبون.
- إذا الهاتف لا يدعم مشاركة صورة، يفتح واتساب برسالة جاهزة تحتوي أسماء الأجهزة والأسعار وروابط الصور.

مهم:
- لم يتم تعديل نسخة الكمبيوتر index.html.
- لم يتم استخدام _worker.js.
- تم الحفاظ على تعديل كأس العالم السابق الموجود داخل index_phone.html.

طريقة الرفع:
1) فك الضغط.
2) انسخ مجلد public فوق مجلد public في مشروع GitHub Desktop.
3) وافق على استبدال index_phone.html.
4) في GitHub Desktop تأكد أن الملف المتغير هو public/index_phone.html.
5) Commit ثم Push.
