تعديل V3 - زر كتالوج الأجهزة واتساب

سبب المشكلة السابقة:
كان هناك خطأ JavaScript في سكربت الزر، لذلك الزر كان يظهر لكن الضغط لا ينفذ أي أمر.

ماذا يفعل هذا الإصلاح؟
- يبقي الزر ظاهرًا في قسم الأجهزة على الموبايل.
- عند الضغط يفتح واتساب مباشرة برسالة جاهزة.
- الرسالة تحتوي أسماء الأجهزة، الأسعار، وروابط صور الأجهزة الموجودة بالموقع.

طريقة الرفع:
1) فك الضغط.
2) انسخ مجلد public فوق مجلد public في مشروعك.
3) وافق على الاستبدال.
4) في GitHub Desktop تأكد من ظهور تغيير في:
   public/index.html
   public/index_phone.html
5) اكتب رسالة Commit:
   Fix mobile devices WhatsApp catalog button action
6) Commit to main ثم Push origin.

بعد النشر جرّب من الموبايل واضغط Ctrl+F5 أو افتح من نافذة خفية إذا بقي الكاش القديم.
