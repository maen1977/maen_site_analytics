تعديل زر إرسال كتالوج الأجهزة واتساب - V5

ما الجديد؟
- الزر يبقى ظاهر في الموقع باسم: إرسال كتالوج الأجهزة واتساب فقط.
- عند الضغط عليه يظهر مربع لإدخال رقم واتساب الزبون.
- يقبل الرقم بصيغ مثل: 0791234567 أو 962791234567 أو +962791234567.
- يحول الرقم الأردني تلقائياً لصيغة واتساب الدولية.
- يفتح واتساب على رقم الزبون مباشرة والرسالة جاهزة.
- رسالة الواتساب تبقى تحتوي أسماء الأجهزة والأسعار وروابط الصور مع شرح: اضغط هنا لمشاهدة صورة الجهاز.

طريقة الرفع:
1. انسخ مجلد public فوق مجلد public في مشروع GitHub Desktop.
2. وافق على الاستبدال.
3. تأكد من ظهور تغيير في public/index.html و public/index_phone.html.
4. Commit ثم Push.
