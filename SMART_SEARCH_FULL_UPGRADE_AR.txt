ترقية البحث الذكي الشامل
========================

تم تعديل بحث الترددات ليعمل كبحث ذكي حسب طلب المستخدم:

- البحث باسم القناة مثل MBC / beIN / الجزيرة / أون تايم.
- البحث حسب القمر المختار من القائمة: كل قمر لحاله.
- إذا كتب المستخدم اسم قمر داخل البحث مثل "MBC نايل سات" أو "رياضة عرب سات" يتم اعتماد القمر المكتوب.
- إذا كتب المستخدم "كل الأقمار" يتم البحث في كل الأقمار حتى لو كان القمر المختار من القائمة محدداً.
- البحث حسب الدول مثل: قنوات مصرية، قنوات سعودية، قنوات تركية، قنوات إيطالية، قنوات إسرائيلية، إلخ.
- البحث حسب التصنيفات مثل: رياضة، دينية، إسلامية، قرآن، مسيحية، أطفال، أفلام، مسلسلات، أخبار، وثائقي، موسيقى، طبخ، تعليم، راديو.
- دعم البحث المركب مثل: "قنوات مصرية رياضية"، "دينية عرب سات"، "MBC نايل سات"، "رياضة كل الأقمار".
- رفع حدود نتائج البحث حتى لا تختفي النتائج الكثيرة.
- الإبقاء على حقل النظام ظاهراً في البطاقات والجداول: DVB-S / QPSK أو DVB-S2 / 8PSK أو غير مذكور.
- توسيع اقتراحات البحث حتى تشمل عدداً أكبر من المحطات.

تم فحص المشروع بالأوامر:
- npm run check
- node scripts/search-smoke-tests.mjs
