# إصلاح انهيار واجهة كأس العالم

هذا الباتش يصلح رسالة:

`Cannot read properties of undefined ...`

السبب كان أن واجهة صفحة كأس العالم كانت تنهار إذا رجع ملف `standings.json` أو أي ملف مساعد بشكل غير متوقع، فتعطل عرض كل المباريات حتى لو `matches.json` موجود وسليم.

## ماذا يفعل؟

- يمنع أي ملف مساعد من إسقاط صفحة كأس العالم.
- يطبع المباريات حتى لو ملف الترتيب أو القنوات فيه مشكلة مؤقتة.
- يطبع القنوات إذا كانت موجودة، لكن لا يسمح لها بتعطيل الصفحة.
- يحافظ على منع الكاش والتحديث كل دقيقتين.
- لا يحتوي ولا يغيّر: `matches.json`, `standings.json`, `bracket.json`.

## بعد الرفع

1. انتظر Cloudflare Deploy.
2. افتح الموقع واعمل `Ctrl + F5` مرة واحدة.
3. بعدها شغّل GitHub Action: `Update World Cup 2026 data`.
