تصحيح سكرول الماوس لنسخة الكمبيوتر

الملف المعدل الوحيد:
- public/index.html

نوع التعديل:
- CSS فقط.
- لا يوجد تعديل على JavaScript.
- لا يوجد تعديل على showPage أو onclick أو تبويبات الموقع.
- لا يوجد تعديل على ملفات كأس العالم أو scripts أو GitHub Actions.

الهدف:
- إلغاء بقايا كود قديم كان يحبس الصفحة داخل ارتفاع الشاشة.
- إرجاع التمرير العمودي الطبيعي بالماوس.
- إبقاء التبويبات العلوية والعرض الكامل للأقسام كما تم ضبطها.
