إصلاح ترتيب وتحديث مباريات كأس العالم 2026

ماذا يفعل هذا الإصلاح؟

1) يرتب مباريات قسم كأس العالم حسب التاريخ والساعة بتوقيت الأردن Asia/Amman.
2) يثبت حقول وقت الأردن داخل ملفات البيانات: kickoff_jordan, date_ar, time_ar, date_jordan, time_jordan.
3) يرتب كروت الأدوار داخل knockout-live.json حسب الوقت الحقيقي، وليس حسب ترتيب قديم داخل JSON.
4) يصحح رقم المباراة الظاهر على الكرت عندما يكون ESPN event id معروفاً أو عندما يستطيع السكربت التعرف على الفريقين.
5) يجلب نتائج ESPN حسب كل تاريخ من 2026-06-11 إلى 2026-07-19، وليس فقط scoreboard الحالي.
6) يملأ 0-0 عند بداية المباراة إذا لم تصل النتيجة بعد.
7) لا يعيد المباراة إلى 0-0 إذا كانت عندها نتيجة سابقة.
8) يعالج المباريات المنتهية العالقة بحالة "بانتظار التحديث" عندما يجد نتيجتها في ESPN.
9) يعيد مزامنة الملفات matches.json و bracket.json و knockout-live.json حتى تكون النتيجة والحالة ورقم المباراة متطابقة بينها.
10) ينشئ تقريراً باسم public/worldcup-2026/jordan-order-consistency-status.json بعد كل تشغيل.

1) افتح المشروع في GitHub Desktop.
