هذه هي النسخة الأحدث الموحّدة من مشروع معن حنونة للستلايت.

تحتوي على آخر التعديلات المهمة:
- إعادة تصميم قسم آخر التحديثات كـ "مركز تحديثات الترددات" بشكل أنظف وأحدث وموجّه للزائر.
- تحسين محتوى آخر التحديثات ليعرض معلومات مفيدة مثل القناة، القمر، التردد، والحالة بدل عبارات برمجية داخلية.
- إصلاح SEO: توحيد canonical و og:url على maensat.pages.dev وإصلاح صورة المشاركة.
- إزالة manifest المكرر غير الموجود manifest.webmanifest والاكتفاء بـ site.webmanifest.
- إبقاء قسم التحديثات خفيفًا: يتم تحميل ملف التحديثات فقط عند فتح القسم.
- إبقاء بحث الترددات بدون قائمة اقتراحات مزعجة، مع استمرار البحث نفسه بشكل طبيعي.
- إزالة ملف الترددات versioned القديم عند توليد الملفات حتى لا تنتشر ملفات قديمة داخل public.
- تثبيت إصدارات حزم Netlify بدل استخدام latest لتقليل مفاجآت البناء مستقبلًا.
- الحفاظ على مبدأ الخطة المجانية: ملفات ثابتة + كاش + تحميل عند الحاجة، بدون استهلاك API إضافي.

طريقة التجربة على الكمبيوتر:
1) فك ضغط هذا الملف في مجلد جديد وفاضي.
2) افتح مجلد public.
3) شغّل الملف: تشغيل-محلي.bat إذا كان موجودًا.
   أو افتح CMD داخل public وشغّل:
   py -m http.server 8080
4) افتح المتصفح على:
   http://localhost:8080/index.html#updates
   أو:
   http://localhost:8080/index.html#frequencies

مهم:
لا تفتح index.html مباشرة بالضغط عليه لأن ملفات JSON و CSS و JS قد لا تُحمّل بشكل صحيح من file://.
ولا تخلط ملفات من نسخ ZIP مختلفة.
